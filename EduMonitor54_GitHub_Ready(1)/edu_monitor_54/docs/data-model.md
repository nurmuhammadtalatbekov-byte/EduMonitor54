## Hisoblash
Kunlik indeks = 5 ko‘rsatkichning arifmetik o‘rtachasi.

Trend = tanlangan davrdagi o‘rtacha indeks − oldingi teng davrdagi o‘rtacha indeks.

Holat:
- 85–100: A’lo 🟢
- 70–84: Yaxshi 🔵
- 60–69: Rivojlanmoqda 🟡
- 0–59: E’tibor kerak 🔴
